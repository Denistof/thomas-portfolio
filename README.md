# Thomas Portfolio — BeThom

Portfolio responsive d'un graphiste freelance, réalisé dans le cadre de la formation **Product Builder No Code & IA**.

## Présentation

Ce projet consiste à intégrer une maquette Figma en créant un site web responsive avec HTML, CSS et JavaScript.

Le site présente Thomas, ses articles récents, ses projets graphiques et un formulaire de contact.

## Technologies utilisées

- **HTML5** — structure et contenu
- **CSS3** — mise en page, styles et responsive design
- **JavaScript** — menu mobile et interactions
- **Figma** — maquettes de référence
- **Visual Studio Code** — développement
- **GitHub** — hébergement du code source et suivi des versions

## Fonctionnalités

- Interface adaptée aux ordinateurs et aux smartphones
- Navigation entre les sections
- Menu hamburger sur mobile
- Présentation des articles récents
- Galerie des projets
- Téléchargement du CV au format PDF
- Formulaire de contact en mode démonstration
- Liens vers les réseaux sociaux

**Remarque :** le formulaire affiche un message de confirmation de test, mais n'envoie pas encore d'e-mail.

## Installation et utilisation

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le dossier du projet dans Visual Studio Code.
3. Lancer `index.html` avec l'extension Live Server, ou ouvrir directement le fichier dans un navigateur.
